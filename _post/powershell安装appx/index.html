🚀 使用 PowerShell 轻松安装 APPX/MSIXBUNDLE 文件

本教程将引导您如何使用 PowerShell 手动安装 Windows 应用（.appx 或 .msixbundle 格式）。这对于没有预装 Microsoft Store 的系统（如 LTSC 版本）或需要离线安装的场景十分甚至九分有用 (homo特有的十比九大)

核心工具

  • Microsoft Store 网站: https://apps.microsoft.com/apps - 用于查找应用并获取链接
  • APPX 链接生成器: https://store.rg-adguard.net - 用于从下载微appx,msix…等安装包

第一步：获取应用安装包 📦

  1. 查找应用: 访问 Microsoft Store 网站，搜索您需要安装的应用，例如 “HEVC 视频扩展”

  2. 复制链接: 进入应用页面后，从浏览器地址栏复制完整的 URL。

  3. 生成下载链接: 打开 store.rg-adguard.net，将刚才复制的 URL 粘贴到输入框中，然后点击右侧的“✔️”按钮。

  4. 下载文件: 页面将列出所有相关文件。您需要下载：

    • 主程序包: 文件后缀为 .appx 或 .msixbundle 的是应用本体。
    • 所有依赖项: 其他以 .appx 结尾的文件是必需的依赖库。
      对于复杂的应用（如 Microsoft Store 本身），您会看到多个依赖项。请确保下载与您的系统架构（通常是 x64）匹配的版本。

    常见的依赖项包括：

    • Microsoft.VCLibs
    • Microsoft.UI.Xaml
    • Microsoft.NET.Native.Framework

第二步：使用 PowerShell 进行安装

  1. 以管理员身份运行 PowerShell:
    按win+x，然后选择选择 Windows PowerShell (管理员)
    (或是营销号常见操作：我们按住win+r，然后输入powershell)

补充：关于“应用安装程序”

部分 Windows 版本（如专业版）内置了“应用安装程序”，允许用户通过双击 .appx 或 .msixbundle 文件来安装应用。它会自动处理依赖关系（例如把上面的blabla全自动装好）
